# FERMENT

Experimental Motion artisan sourdough (Level C).

- Concept: [`concept.md`](./concept.md)
- Demo: `/demos/ferment/`
- Desktop: sticky horizontal process (9 stages)
- Mobile / reduced-motion: vertical chapters
- Form: Reserve a loaf (RHF + Zod, mock submit)

```bash
pnpm --filter ferment dev
# http://localhost:3000/demos/ferment/
```

Stack: Next.js static export, Tailwind, Framer Motion, Syne + Literata.
